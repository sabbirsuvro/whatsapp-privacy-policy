Privacy Policy

WhatsApp Privacy by Sabbir Ahmed

Last Updated: November 26, 2026

1. Introduction

This independent Chrome extension provides privacy features while using WhatsApp Web.

2. Data Collection

The extension does not collect or transmit personal information to external servers.

3. Local Storage

User preferences, privacy settings, PIN hash and auto-lock configuration are stored locally using Chrome storage.

4. WhatsApp Web Content

The extension processes relevant WhatsApp Web content locally in the browser to provide message blur, contact name blur, profile picture blur, media blur and chat preview protection.

It does not intentionally transmit chat messages, contacts, images or videos to external servers.

5. Data Sharing

We do not sell or share users' personal information with third parties.

6. Security

Privacy settings and PIN hash are stored locally. Users should keep their browser profile secure.

7. Third-Party Disclaimer

This extension is independently developed and is not affiliated with, endorsed by, or officially connected to WhatsApp or Meta Platforms, Inc.

8. Policy Updates

This policy may be updated when the extension's functionality or data practices change.
